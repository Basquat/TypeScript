# Manual do usuário

## Entrar e sair

1. Abra o sistema (http://localhost:5173 em ambiente local).
2. Digite e-mail e senha, ou use um dos botões de acesso rápido das contas de demonstração.
3. Não tem conta? Clique em **Criar conta** e escolha **Psicólogo** (exige CRP, ex.: `03/12345`) ou **Cliente**.
4. Para sair, use o botão **Sair** (ícone no topo do menu).

## Administrador

| Quero… | Onde | Como |
| --- | --- | --- |
| Ver a situação geral | Visão geral | Totais de usuários, psicólogos, pacientes e contas por situação |
| Cadastrar usuário | Usuários → Novo usuário | Escolha o perfil; para psicólogo, informe o CRP |
| Bloquear/ativar/inativar | Usuários → editar | Altere a **situação**. O efeito é imediato |
| Mudar perfil | Usuários → editar | Altere o **perfil**. Não é possível mudar o próprio |
| Cadastrar paciente | Pacientes → Novo paciente | Escolha o psicólogo responsável |
| Ver quem fez o quê | Auditoria | Use a busca para filtrar |

## Psicólogo

| Quero… | Onde | Como |
| --- | --- | --- |
| Ver meu dia | Hoje | Sessões do dia e indicadores da semana |
| Cadastrar paciente | Pacientes → Novo paciente | Nome obrigatório; demais dados opcionais |
| Encontrar paciente | Pacientes | Busque pelo nome; alterne entre ativos e arquivados |
| Arquivar/reativar | Paciente → Arquivar | Arquivado não recebe novos agendamentos; histórico fica |
| Agendar sessão | Agenda → Nova sessão | Escolha paciente, data, hora, duração e valor. Em repetição, escolha "Semanal · N semanas" para uma série |
| Registrar a sessão | Sessão | Mude a situação (realizada, faltou, cancelada), marque como paga e escreva a anotação |
| Responder pedidos | Solicitações | **Confirmar** cria a sessão automaticamente; **Recusar** permite deixar recado |
| Atualizar perfil | Perfil profissional | Área, apresentação, valor, horários de atendimento e formação |

As anotações são criptografadas e só você as vê.

## Cliente

| Quero… | Onde | Como |
| --- | --- | --- |
| Encontrar psicólogo | Encontrar psicólogo | Busque por nome ou área |
| Pedir horário | Perfil do psicólogo | Escolha um horário livre, deixe um recado (opcional) e envie |
| Acompanhar | Minhas consultas | Veja pedidos pendentes, respostas e consultas confirmadas |
| Cancelar pedido | Minhas consultas | Possível enquanto estiver pendente |

## Mensagens comuns

| Mensagem | Significado |
| --- | --- |
| "E-mail ou senha incorretos." | Confira os dados |
| "Esta conta não está ativa." | Conta bloqueada ou inativa — fale com o administrador |
| "Sessão expirada. Entre novamente." | O login vale 8 horas |
| "Horário ocupado por uma sessão com …" | Escolha outro horário |
| "Você não tem permissão para acessar este recurso." | Ação fora do seu perfil |
